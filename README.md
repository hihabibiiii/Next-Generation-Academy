# Next Generation Academy Institute Website

A modern, responsive institute website built with HTML5, CSS3, and vanilla JavaScript.

## Files

- `index.html` contains the semantic page structure.
- `css/style.css` contains the responsive design system and animations.
- `js/script.js` contains dynamic course data, sliders, modals, validation, counters, and localStorage submission simulation.

## Customize

Update institute details in `index.html` and the `institute`, `courses`, `features`, `facilities`, and `testimonials` arrays in `js/script.js`.

## Run

Open `index.html` directly in a browser. No build tools or dependencies are required.
